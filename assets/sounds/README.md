# Walk sounds

Two short sounds the guided walk plays while a page opens. `tick.wav` loops
from the moment the browser is launched until the page has loaded, and
`ding.wav` plays once when it has. Both are CC0 (public domain dedication)
and were re-encoded to 16-bit PCM, 44.1 kHz, stereo with ffmpeg on
2026-09-19.

- `tick.wav` (3.66 s): "clock-1.wav", OpenGameArt node 16323, by AntumDeluge, CC0.
- `ding.wav` (2.52 s): Freesound sound 611113 by 5ro4, CC0.

A copy of either file under `~/.local/share/pipulate/` is played instead of
the one here, so you can swap in your own without touching the repo. No file
in either place means no sound.
