Levinix: Write Once, Run Anywhere Without Electron

Levinix is the packaging architecture behind the NPvg stack (Nix + Python + vim + git): a zero-dependency "Magic Cookie" bootstrap that turns any macOS, Linux, or Windows WSL folder into a self-updating, reproducible local web application.

Inspect the bootstrap contract first:

curl -fsSL https://levinix.org | less

Then run it:

curl -fsSL https://levinix.org | bash

AI agents requesting Accept: text/markdown (RFC 9110 Section 12) at this exact URL receive the raw Markdown specification directly.

The 3-Repo Nix Flake Trilogy

  • pipulate/levinix (The Electron Killer): Minimal (~130-line, pure pip + virtualenv) Magic Cookie WORA app packager.
  • miklevin/python_nix_flake (The Docker Killer): Standalone Rust uv + Python 3.13 Data Science & AI Agent starter flake with .#default and .#quiet shells.
