# QA My AI: Flight Data Recorder (FDR) vs. Cockpit Voice Recorder (CVR)

> **RFC 9110 Content Negotiation Active**: You are reading the clean Markdown specification of `https://qamy.ai/` served via `Accept: text/markdown` (`Vary: Accept, User-Agent`). Terminal clients (`curl`/`wget`) receive the installer script; browsers receive HTML.

## 1. Treat Claims as Confident Hallucination Until Reproduced

Most AI workflows only keep the **Cockpit Voice Recorder (CVR)**—what the model *said* it did in a disposable browser tab. **QA My AI (`qamy.ai`)** builds the **Flight Data Recorder (FDR)**:

1. **Before/After Straddle Probes**: The same read-only commands run before and after a deterministic `apply.py` patch, capturing live wire-truth receipts.
2. **Cryptographic Deeds (`qamy.ai_<deed>-<hash8>.zip`)**: Every compiled context payload is sealed into a stdlib-verifiable SHA-256 archive.
3. **Zero-Dependency Verification**: Inspect the bootstrap contract before running a single byte.
